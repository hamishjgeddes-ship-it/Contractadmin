<analysis>**original_problem_statement:**
The user wants to build a secure, simple client portal called Build Compliance for the construction industry. This portal will allow clients of Morrissey Law + Advisory (MLA) to have clear visibility over their projects. The backend will be operated by MLA lawyers and contract administrators to manage contract administration, standardize workflows, generate notices, track deadlines, and create a defensible audit trail.

**PRODUCT REQUIREMENTS:**
- **Users:** Internal (MLA - full control) and External (Clients - read-only).
- **Core MVP Features:**
    1.  **Project Setup:** Backend functionality to define projects with client details, contract info, key dates, and assigned teams.
    2.  **MLA Operations Portal:** A dashboard for MLA staff to manage all projects, view deadlines, and run structured contract admin checkups.
    3.  **Structured Digital Questionnaires:** Reusable forms for capturing information on risk events like delays, variations, etc.
    4.  **Document & Notice Outputs:** Generate and issue templated notices and reports, tracking their status (draft, issued, responded, closed).
    5.  **Deadlines & Alerts:** A central register for project deadlines with automated reminders and alerts.
    6.  **Client Portal:** A read-focused view for clients showing project overviews, key dates, issued notices, and risks.
- **User-Requested Features (added during development):**
    - **Dashboard:** An Asana-style dashboard rolling up all active projects, deadlines, and notices. Must include project name, value, completion date, outstanding items, and a Request Assistance button.
    - **Project Creation:** An Add New Project button on the dashboard for lawyers/admins.
    - **Document Library:** A folder for each client to access documents uploaded by MLA.
    - **Construction Program (Gantt Chart):** A Gantt chart view per project to manage tasks, and subcontractors, and generate/issue/sign subcontracts. Subcontractors should be invited to the system.
    - **Gantt Chart Enhancements:** Action buttons on each task (Issue Subcontract/Notice) and a feature to upload a construction program file (e.g., CSV/Excel) to auto-populate tasks.
    - **Integrations:** Simple API integrations (e.g., Teams, Zoom).

**User's preferred language**: English
